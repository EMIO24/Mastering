# Week 1 mastery checklist

Record evidence in [your progress notes](assignments/progress.md). Leave an item unchecked until you can do it without copying an answer.

## Lesson 1 — Fundamentals

- [ ] I can distinguish strings, integers, floats, booleans, and `None`.
- [ ] I can explain `/`, `//`, `%`, comparisons, and Boolean operators.
- [ ] I can choose between a list, tuple, dictionary, and set.
- [ ] I can trace a condition and a loop, including the empty-input case.
- [ ] I can write a function that returns a result instead of only printing it.
- [ ] I can read and update nested product data.
- [ ] I completed and marked the diagnostic out of 100.
- [ ] I reached 80/100 and at least half the points in each section, or completed targeted practice and a fresh retry.

## Lesson 2 — Defensive programming

- [ ] I can read a traceback and locate the failing line.
- [ ] I can explain `try`, `except`, `else`, `finally`, and `raise`.
- [ ] I catch specific expected exceptions around the operation that may fail.
- [ ] I distinguish an invalid integer from an out-of-range integer.
- [ ] An invalid sale leaves the product's stock unchanged.
- [ ] My program handles unknown products and repeated invalid input.

## Lesson 3 — Persistence

- [ ] I can explain `r`, `w`, and `a`, including when data is overwritten.
- [ ] I use `with open(...)` and UTF-8 for text files.
- [ ] I can explain JSON file operations versus JSON string operations.
- [ ] I can read CSV rows and convert numeric fields deliberately.
- [ ] My loader validates data structure as well as JSON syntax.
- [ ] My CLI starts with an empty inventory when its data file is missing.
- [ ] My CLI refuses to overwrite a corrupt or structurally invalid inventory file.
- [ ] Successful changes survive a restart.
- [ ] Failed saves do not produce a success message or commit a change in memory.
- [ ] My CSV export has the required header and correct rows.

## Final demonstration

- [ ] Add two products, sell one, quit, restart, and show the correct quantities.
- [ ] Demonstrate one bad input, one unknown product, and one oversell.
- [ ] Demonstrate malformed JSON and a valid JSON file with the wrong structure using disposable copies.
- [ ] Explain the journey from keyboard input to validation to memory to disk.
- [ ] Describe one limitation and one improvement for a future lesson.
