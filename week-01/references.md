# Week 1 references

Selected primary documentation, checked on September 7, 2026. Use these as companions to the lessons, not as a requirement to read entire sites.

## Lesson 1: Python tutorial

[Python tutorial](https://docs.python.org/3/tutorial/)

Read sections 3-5 for types, control flow, functions, and collections. Attempt the diagnostic first.

## Lesson 2: Python errors and exceptions

[Python errors and exceptions](https://docs.python.org/3/tutorial/errors.html)

Focus on handling, raising, else, and cleanup. Explain which errors the checkout should catch.

## Lesson 3: Python JSON reference

[Python JSON reference](https://docs.python.org/3/library/json.html)

Compare load/dump with loads/dumps; practise saving one inventory document.

## Lesson 3: Python CSV reference

[Python CSV reference](https://docs.python.org/3/library/csv.html)

Read DictReader and DictWriter, including newline handling; export products with commas in their names.

## Offline use and versions

The assignment checker works without internet or extra packages. These references are web links, not bundled copies: save relevant pages from your browser while online if you want to read them offline. Keep your own notes in this folder.

Python and PostgreSQL links can follow newer documentation over time; select the version matching your installation. Django links deliberately use the 5.2 documentation as a consistent reference, not a claim that it is the newest release. Recheck library setup instructions when the relevant week begins.
